Portfolio CV - Hà Vũ Mạnh

1. Giới thiệu dự án

Đây là dự án xây dựng website Portfolio CV cá nhân của Hà Vũ Mạnh, sinh viên ngành Công nghệ Thông tin.

Website được phát triển bằng HTML5 và CSS3 nhằm giới thiệu thông tin cá nhân, kỹ năng, các dự án đã thực hiện, quá trình học tập và thông tin liên hệ.

2. Mục tiêu dự án

Thực hành xây dựng cấu trúc website bằng HTML5.

Sử dụng CSS3 để thiết kế và định dạng giao diện.

Làm quen với thiết kế website Responsive.

Rèn luyện kỹ năng tổ chức và quản lý mã nguồn.

Thực hành sử dụng Git và GitHub để lưu trữ, chia sẻ dự án.

3. Công nghệ sử dụng

HTML5: Xây dựng cấu trúc nội dung website.

CSS3: Thiết kế giao diện, màu sắc và bố cục.

Google Fonts: Sử dụng font chữ Inter.

Visual Studio Code: Công cụ viết và chỉnh sửa mã nguồn.

Git và GitHub: Quản lý và lưu trữ mã nguồn.
